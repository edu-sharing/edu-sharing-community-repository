# edu-sharing community repository
===========================

The edu-sharing open-source project started in 2007 to develop networked E-Learning environments for managing and
sharing educational contents inter-organisationally.

Documentation
-------------
place an .sh script in scripts folder. all scripts are executed when database check is done. 
the running order follows from script names that are sorted ascending.
when a script is successfully executed ``` exit 0 ```, a file is created 
under alf_data/scripts_processed and not processed again.
